# برنامج كشف درجات أعمال السنة المدرسية (School Work & Grade Sheet)

تطبيق أندرويد حسابي متكامل مصمم خصيصاً للمعلمين والمعلمات والمدارس لحساب ورصد درجات أعمال السنة، المواظبة، الواجبات، الشفوي، والتحريري، وحساب المجاميع والنسب المئوية آلياً، مع إمكانية تصدير كشوفات PDF و Excel وحفظها ومشاركتها مباشرة.

---

## 🌟 مميزات التطبيق

1. **واجهة تحكم مطابقة ومصممة بأعلى معايير الدقة والجمالية:**
   - تصميم معدني فخم (Brushed Metallic 3D) مع إطارات ذهبية وأزرار ثلاثية الأبعاد بارزة.
   - كليشة المدرسة والعام الدراسي (ميلادي وهجري) قابلة للتعديل والتحرير بنقرة واحدة.
   - بيانات الأستاذ، المادة، الصفوف، والشعب قابلة للتخصيص الكامل.

2. **الفصل الدراسي الأول والفصل الدراسي الثاني:**
   - إدارة مستقلة وكاملة لكل فصل دراسي (الفصل الأول / الفصل الثاني).
   - إمكانية التنقل السلس بين الشهور والشعب والمواد.
   - ميزة **إغلاق الشهر الحالي وبدء شهر جديد** مع استنساخ بيانات الطلاب وتصفير الدرجات لبدء التقييم الجديد.

3. **جدول رصد الدرجات التفاعلي:**
   - **م (الرقم التسلسلي):** ترتيب تسلسلي تلقائي للطلاب.
   - **الاسم:** اسم الطالب الكامل.
   - **المواظبة:** رصد درجات الحضور والانضباط.
   - **الواجبات:** رصد درجات الواجبات والمهام المدرسية.
   - **الشفوي:** رصد درجات المشاركة والاختبار الشفوي.
   - **التحريري:** رصد درجات الاختبارات التحريرية والشهرية.
   - **المجموع:** حساب تراكمي فوري وتلقائي للدرجات.
   - **النسبة % والتقدير:** احتساب النسبة المئوية الدقيقة وعرض التقدير (ممتاز، جيد جداً، جيد، مقبول، ضعيف) بألوان تمييز بصرية.

4. **خيارات الحفظ والتصدير المتقدمة:**
   - **حفظ بصيغة PDF:**
     - تصدير كشف كامل للفصل الدراسي والشهر بجدول رسمي منسق مع الترويسة والتواقيع.
     - تصدير بطاقة درجات فردية لكل طالب على حدة بصيغة PDF.
   - **حفظ بصيغة Excel:**
     - تصدير كشف درجات الشهر والفصل بصيغة CSV و Excel متوافقة بالكامل مع Microsoft Excel و Google Sheets مع دعم كامل للحروف العربية بتشفير UTF-8 BOM.
     - تصدير سجل درجات الطالب الفردي بصيغة Excel.
   - **حذف وتصفير العمليات الحسابية:**
     - إمكانية تصفير درجات الطالب أو حذف سجله بنقرة واحدة.

5. **المتغيرات والرموز والدرجات العظمى:**
   - نافذة إعدادات متقدمة تتيح للمعلم تخصيص الدرجات العظمى لكل بند (درجة المواظبة العظمى، الواجبات العظمى، الشفوي العظمى، التحريري العظمى) لحساب النسب المئوية وفق لائحة التقويم المعتمدة.

6. **النسخ الاحتياطي وإعادة ضبط المصنع:**
   - **نسخة احتياطية:** تصدير كافة بيانات الفصول والطلاب والدرجات إلى ملف JSON ومشاركتها عبر الواتساب أو حفظها بالهاتف.
   - **استعادة البيانات:** استيراد النسخ الاحتياطية واسترجاع البيانات بضغطة زر.
   - **إعادة ضبط المصنع:** زر إعادة الضبط بجوار رقم الهاتف لمسح كافة السجلات بعد تأكيد المستخدم.

## 📱 التوافق والمتطلبات التقنية

- **نظام التشغيل المدعوم:** Android 7.0 (API 24) فما فوق، ومُحسّن بالكامل لنظام **Android 15 (API 35/36)**.
- **لغة البرمجة:** Kotlin 2.2.10
- **واجهة المستخدم:** Jetpack Compose & Material Design 3 (M3)
- **قاعدة البيانات:** Room Database 2.7.0 مع دعم كامل للتخزين المحلي دون الحاجة لإنترنت (Offline-first).
- **محرك إنشاء التقارير:** Android Graphics & PdfDocument Engine

## 🛠️ خطوات البناء والتشغيل (Build & Run)

1. استيراد المشروع في **Android Studio Ladybug / Koala** أو تشغيله عبر سطر الأوامر:
```bash
gradle assembleDebug
```
2. لتوليد حزمة APK نهائية قابلة للتثبيت على هواتف Android 15:
```bash
gradle assembleRelease
```
3. ملف الـ APK الناتج سيتواجد في المسار:
`app/build/outputs/apk/debug/app-debug.apk` أو `app/build/outputs/apk/release/app-release.apk`
